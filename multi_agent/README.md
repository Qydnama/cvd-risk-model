# Прототип для Ассайнмента 2

Тема: **многоагентная ИИ-система для интерпретируемой оценки пятилетней вероятности смерти от сердечно-сосудистых причин**. Используется существующая исследовательская модель `minimal_v1`. Проект не предназначен для диагностики, выбора лечения или клинического применения; модель не валидирована для Казахстана.

## Что готово

- Архитектура из шести ролей с входами, выходами, инструментами и критериями завершения: [ARCHITECTURE.md](ARCHITECTURE.md).
- Работающий прототип: оркестратор передаёт сырые поля агенту проверки; тот передаёт типизированный `PatientInput` агенту прогноза. Прогноз выполняет зафиксированная модель, а не LLM.
- Явное состояние `PrototypeState` на время запуска, Pydantic-контракты, два источника данных: release-схема и сериализованный ML pipeline.
- Конфигурация Deep Agents для двух специализированных ролей. Для её запуска с реальным LLM нужен ключ провайдера из переменной окружения (`.env.example` показывает имена; `.env` автоматически не загружается). Основная демонстрация не требует ключа.

Это **не** финальная система. Агенты доказательств, объяснения и проверки безопасности пока только описаны. Логи, измерение нагрузки, лимиты, повторные попытки и набор сценариев будут добавлены к Ассайнменту 4. Ошибки входа и модели уже приводят к явному отказу без подстановки фиктивного риска.

## Запуск

Из `multi_agent/`:

```powershell
uv sync --locked --group dev
uv run --locked python -m cvd_agents.cli --age 58 --sex male --bmi 28.1 --smoking-status former --hypertension --no-diabetes --general-health good
uv run --locked pytest -q
```

CLI печатает JSON с `validation` и `prediction`. Если отсутствует поле или значение вне схемы, `prediction` остаётся `null`. Точность результата определяется только реальным `minimal_v1`. Проверка Stage 9 сверяет SHA артефактов до загрузки joblib. Отдельный корневой `uv.lock` и файлы модели не меняются. Версии научных библиотек в этом подпроекте соответствуют release manifest.

## Что показывать на сдаче

1. Схему и таблицу ролей в `ARCHITECTURE.md`.
2. Команду CLI выше и её JSON: переход `ValidationResult → PatientInput → PredictionResult`.
3. Повторный запуск с `--age 39`: отказ валидации и отсутствие прогноза.
4. `tests/test_prototype.py`: проверку реального pipeline и остановки на ошибочном входе.

История полной экспериментальной реализации сохранена отдельно в ветке `agent/multi-agent-cvd-risk`; этот прототип находится в `agent/assignment-2-prototype`.
